# 🗳️ Urna Eletrônica - Projeto JavaScript

Este projeto simula o funcionamento básico de uma urna eletrônica, permitindo votos para cargos fictícios de **vereador** e **prefeito**. O sistema é construído com foco em manipulação de DOM, lógica condicional e arrays em JavaScript puro.

## 🔧 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript 

## 🧠 Funcionalidades

- Interface interativa para votação com números
- Reconhecimento de candidatos por número
- Suporte a votos nulos e em branco
- Etapas de votação para múltiplos cargos
- Exibição de imagens dos candidatos
- Mensagem final ao término da votação
- Registro de votos no console (para fins de aprendizado)

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com fins educacionais, com o objetivo de praticar:

- Manipulação do DOM com JavaScript puro
- Lógica de controle de interface
- Estruturação de dados em arrays e objetos
- Criação de interfaces dinâmicas
